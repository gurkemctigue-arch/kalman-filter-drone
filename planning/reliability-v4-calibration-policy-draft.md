# 开发定标与正式登记的候选规则

本文件是候选规则，**不是 REGISTERED 配置，不授权读取留出结果**。最终采用值与来源须写入四法机器可读登记，并在第一条正式 `stage1_velocity` 飞行前冻结。正式数据不能用于选择数值。

工程候选门：整段 `base_link` 距离 RMSE ≤ 1.0 m、高度 RMSE ≤ 0.40 m；导航有效覆盖 ≥ 0.80；独立物理真值覆盖 ≥ 0.99；完整请求任务的物理身份已知覆盖 ≥ 0.75 且错误个体数为零；末端距离与高度均须按现有定义连续稳定至少 3 s。现有距离带 `max(0.5 m, 10%期望距离)`、高度带 0.25 m、缺证/删失处理和所有安全时效不变。正式登记前以两类六组开发矩阵检查可行性，不能把故意压力工况的性能失败改写为通过。

四估计器候选定标方法如下。

| 参数 | 候选规则及理由 |
| --- | --- |
| 固定传感器协方差 `R0_sensor[class]` | 分类别使用最终开发版本 clean 录制中所有去重、几何独立有效的融合前 `R_geometry_world_m2` 的完整 3×3 算术平均。不得只选在线已接受观测，也不以目标真值拟合。正半定矩阵的平均仍正半定，记录数值与特征值 |
| 过程模型 | 与实际导航一致的分段常加速度模型，候选加速度标准差 1.0 m/s²；两种 KF 和公共门控使用相同值 |
| 共同初始协方差 | 候选 `diag(1,1,1,4,4,4)`，位置单位 m²、速度单位 m²/s²，两个 KF 与公共门控一致 |
| 共同初速度 | `[0,0,0]` m/s，当前方法均不读取未来位置或真值估初速；与“复现在线 KF 的实际初始化速度”分开说明 |
| EMA | 候选每个真实接受测量的 `alpha=0.35`；不把回调重复或定时器重复当新观测 |
| 公共门控 | 固定几何加位姿 `R_geometry + R_pose`、共同 P0、阈值 9.21；四方法使用同一因果接受序列 |
| 共同支持门 | 候选完整时间网格真值及四方法共同支持覆盖 ≥ 0.80；报告全部计划十对和有限/已核验配对数。覆盖不满足则保留描述结果，不称完成十次有效配对 |

候选定标来源固定为最终同源 12 格核心开发计划中 `person_stage1_velocity_seed004` 与 `car_stage1_velocity_seed004` 两个完整槽，不从多条同条件试验中按 RMSE 或 PASS 挑包。最终实际计划路径、计划摘要、两个终态 record、完整导出 arrays 与审计的文件 SHA 必须写入定标证据；若飞行源需修订，则保留旧集并以前瞻新开发计划重新定义来源，不能让旧正式留出数据进入定标。

取每个槽从 FOLLOW 至完整已记录 clock 末尾的融合前独立几何有效机会；去重键为该槽内 `(target_uuid, track_id, acquisition_source_s)`，采用导出器保存的原始采集精度，重复定时器消息不加权。保留对应 acquisition_id 清单、全部机会数、几何有效数与排除原因，不按在线融合是否接受筛样本。均值矩阵须有限、对称且最小特征值严格大于 `1e-12` m²，才满足当前登记器的正定要求；若不满足则拒绝登记并解释来源，不临场添加未登记 jitter。两种 KF 共享的实时 `R_pose` 不参与 R0_sensor 的平均，也不重复添加。

原生在线复现继续用 float64 绝对容差 `1e-8`；消息 `covariance`/`prediction_age_s` 先按已声明 float32 精确量化再比较，量化后一 ULP 差异也拒绝。输出时间、发布与实际交付仍分开，原 0.60/0.75/0.50/0.05 s 边界不变。

开发可行性观察：Humble04 car clean20s 的 204 个独立几何有效样本，平均 R_geometry 的对角线约 `[0.0508621, 0.0885436, 0.000400136]` m²，最小特征值约 `0.000400035`。它仅是初步数量级检查，不能直接代替最终版本两类来源或 REGISTERED R0。输入为真实 export03 arrays，SHA256 `ed4e4f9935688f15fce9a00001112dba0d5fc60b8710cd81c17d96d2b11cde71`；原飞行状态和旧失败保持不变。
