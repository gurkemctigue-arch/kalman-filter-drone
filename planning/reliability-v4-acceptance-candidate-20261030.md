## 4. 稳定带与末端三秒：已有定义，不是整体 RMSE 门

- 距离带 `max(0.5 m, 0.10×期望距离)`：核心行人 0.5 m、汽车 0.9 m；若扩展远距为 7/12 m，则依原公式为 0.7/1.2 m，不能固定抄核心数值。
- 高度带为 0.25 m；两个维度分别要求最后连续在带、真值有效、导航有效且控制活动的后缀，持续至少 3.0 s 并保持到评价终点。原最大证据间隙为 0.15 s；重复时刻不能证明稳定。
- `first_sustained_in_band_time_s` 仅表示曾持续入带；验收采用 `settled_through_interval_end`。两者不能互换。
- 缺真值、停控、错/未知任务、导航无效、时间缺口或超带会中断后缀。未满足者 `settling_time_s=null` 且 `settling_right_censored=true`，不填 0，不删尾段，也不把两维的最小值合成稳定成功。
- 保留 `require_final_window_settled=true` 为本候选明确要求；core 仍需最终登记。稳定带不会自动推出合理的全程 RMSE 上限。

## 6. 计划遮挡会限制可达到的覆盖，但不得删分母

既有任务在 FOLLOW+12 s 请求短遮挡、+25 s 请求长遮挡，长遮挡最低驻留 3 s，成功 ACK 后额外保留 0.05 s 渲染 allowance。显式重选最早在 +32 s 且实际 LOST/HOVER、有新鲜检测框时请求；不能把长遮挡打开时刻当作重选确认。

导航可在短遮挡内按原 0.75 s 有效期预测；因此不能简单把全部遮挡时长扣成导航无效。长遮挡及显式重选等待必然包含合法悬停区间：最后有效测量源戳加 0.75 s 后至新任务有效导航恢复前，均占全导航分母。真实恢复交付、任务匹配与网格相位还会增加不可用格数。该预计不可用量须在新正式结果前按固定任务日程、时延预算和原门限算出，不能用一次已见失败时长反向定门。

物理身份不能由预测状态或稳定 UUID 证明。现有离线匹配将两次 shutter 请求区间分别向前/后扩展 1 s，保护区内的源图身份保持 UNKNOWN；这与 0.05 s 渲染 allowance 是两个不同合同。还需计入确认前、无帧及不可分辨交叠；前景几何充分证书只能证明满足其严格条件的帧，不能替所有交叠消除 unknown。

配套 JSON 提供待填的 `opportunity_budgets`：对每类别/组/条件先给任务长度、最后测量/确认的因果预算和预计不可证格数 `U_min`，再求理想证据上限 `C_max=(N-U_min)/N`。必须使用确切网格及区间并集去重，列明源图时间/交付时间映射假设；粗略 `1-遮挡秒数/45` 不能代替它。如果阈值高于合法任务本身的可达上限，应在正式前解决任务设计或需求矛盾，留下协议修订；不能删掉合法悬停时间或把 UNKNOWN 改正确。

额外派生“可观察时段覆盖”和 UNKNOWN 原因分解可用于修复定位，但须与全任务主分母并列，不替代主门。若决定引入额外 unknown 或最长非计划间断的新硬门，还需实现、验证和前瞻登记；本次候选不声称这些派生门已存在。
