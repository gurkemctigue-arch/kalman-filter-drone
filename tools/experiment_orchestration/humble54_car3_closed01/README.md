# Humble54 原始汽车三槽的小文件证据快照

本目录复核原开发批次的第 7–9 槽。三个原始槽均为 `PASS`；六项已登记导航工程门槛也分别满足。这里只复核保存的小文件，并未重新运行飞行或用 rosbag 重算结果。

| 原始槽 | 距离 RMSE / m | 高度 RMSE / m | 有效导航覆盖率 | 真值覆盖率 |
| --- | ---: | ---: | ---: | ---: |
| `car_stage1_velocity_seed004` | 0.741770 | 0.150335 | 0.916223 | 1.0 |
| `car_stage1_position_seed004` | 0.704895 | 0.165654 | 0.913679 | 1.0 |
| `car_stage2_crossing_seed004` | 0.868298 | 0.156740 | 0.900398 | 1.0 |

三个槽均为同一随机种子 4、75 秒任务。登记门槛为距离 RMSE ≤ 1.0 m、高度 RMSE ≤ 0.4 m、有效导航覆盖率 ≥ 0.8、真值覆盖率 ≥ 0.99，并要求最终距离和高度稳定窗口均满足。原始导航报告的状态仍是 `RECORDED_WITH_CENSORED_FAILURES`；工程槽通过不意味着报告中的所有局部段落均无失败。

`collect_snapshot.py` 校验计划文件、内部计划摘要和槽记录摘要；调用 SHA 固定的元数据读取辅助脚本，核对源文件清单、原生启动、source clock、行为评价、运行参数、数据归档与退出清理。复核的 127 份小型 JSON/日志全部逐字节复制。连同计划、冻结清单、辅助源码、开始标记、槽记录及矩阵评价日志，清单共含 **153 份原始文件、3,407,808 字节**。所有复制文件均不超过 1 MiB。原始文件的位置、长度、SHA256 和快照相对位置见 `manifest.json`。

保存的 source clock、native startup、surface flight 均为 `PASS`；交叉槽 selected-target safety 亦为 `PASS`。保存的录包关闭、bag integrity、DDS 和桥接运行报告均满足原检查；原始槽无基础设施停止、无残留进程。`owned_stop_observer` 的 `EVIDENCE_COMPLETE` 与其 `NOT_EVALUATED_EXISTING_PROCESS_AUDIT_REMAINS_REQUIRED` 限定同时保留，不能单凭该观察器推断全部运行验收。

| 单独的诊断帧统计 | 644 | 0 | 99 | 743 | 0.866756 |

完整任务身份区间为 17.36–92.76 秒，有 2 次请求任务，原摘要的未确认请求列表为空。诊断帧结果不能替代完整任务结果。整体覆盖率高于 0.8，不能证明每个 `target_uuid` 都达到该门槛，也不能确认未知区间内的物理身份。原身份报告状态 `RECORDED_WITH_EXPLICIT_UNKNOWN_INTERVALS` 保留。

为避免与主代理的在运行仿真竞争资源，未读取、哈希或复制 3,066,769 字节的交叉槽 `physical_identity.json`，也未读取三个 2.4 MB 左右的 `ros.log`；长度来自文件元数据。未读取模型、bag、原始遥测或 JSONL，未启动 WSL/ROS/仿真，未导入算法或评价模块。未独立核验大身份报告及每次 UUID 的覆盖率。原始源清单也不能证明历史上每个飞行进程实际导入的位置。
