# 多目标与动态相机检测补充工具源码快照 v1

本目录保存已独立审查的检测数据提取、评价适配器及合成测试。它为多同类目标和动态相机场景提供**单独的检测补充附件**，不修改在线算法、冻结 42、旧实验数据或现有正式报告流程。

原来的两条 `stage1_velocity seed1000` 静态渲染网格可见子集继续接入原报告；新多目标/动态相机证据使用外部附件及其独立校验器，不能直接交给旧 `build_reliability_v4_report.py` 当作已支持的输入。静态渲染网格也可能由移动相机拍摄，“静态网格”不等于“固定相机”。

**尚未执行实际协议创建、bag 提取、模型推理、可见标签审批或检测报告生成。** 作者的 **47 项测试**分别在 Windows Python 3.12 与 Ubuntu 22.04/Humble 系统 Python 3.10 通过；独立审查在 Windows 复跑作者测试并增加 5 项对抗测试，合计 **52 项通过**。这些均为使用临时合成数据、微型假模型/图像及明确导入源码辅助函数的组件检查，不是正式场景性能、真实消息 ABI 或全飞行准确率验证。此次快照整理没有重跑这些测试。

## 文件与来源

- `prospective_detection_dataset.py`：事前协议、单槽提取与提取记录校验。
- `evaluate_prospective_detection.py`：标签审查素材、显式离线推理、绑定独立审批、评价及补充报告校验。
- `test_prospective_detection.py`、`test_prospective_detection_independent01.py`：47 项作者测试与 5 项独立对抗测试。

- `snapshot_manifest.json`：每个复制文件的原路径、字节数与 SHA-256，以及本地说明文件的校验信息。清单不递归绑定自身，其 SHA 在交接时另行提供。

## 真正执行前必须满足的顺序

1. 先生成真实的 `FORMAL120` 与 `EXTENSION_FORMAL160` 原计划，再显式创建检测事前协议；必须在两计划的**第一次正式飞行尝试之前**完成。工具校验原计划及目录/start/terminal 状态。合成计划不证明真实计划存在；若正式飞行已经开始，不能倒填或伪造一个追溯协议。
2. 协议绑定真实原计划路径/SHA、冻结辅助源码及本工具源码身份。复制工具后须重新检查实际环境、路径及源码身份；不要编辑已审脚本来绕过身份校验。
3. 提取时显式指定**一个原 slot**，推理/评价时显式给出所选录制列表。没有自动批量提取或扩矩阵命令。120+160 共 280 条原计划是保留的分母，不表示本工具会启动 280 次新飞行或自动处理 280 个 bag。
4. 原 bag 全量哈希、两遍读取和模型推理都是重离线任务，必须由主流程安排资源独占空闲窗口，并确认解压临时空间、原输入完整性及全新的外部输出路径。提取、标签与报告输出不得写入原冻结源码、结果符号链接目标、原试验或计划证据目录。
5. 独立审查者查看原 RGB、全画面/全部同类目标的 GT-only 叠图与审查表，明确记录 `APPROVE_VISIBLE_LABELS`、`REJECT` 或 `UNKNOWN`，绑定原图/叠图及审查身份。工具不自动批准可见标签，审查不依赖模型预测。该工作可以由独立代理后续执行，不要求用户手工操作仿真器。
6. 绑定批准项与原 schema2 预测缓存来源后，再按原检测 API 评价并运行新的补充报告校验器。新附件不能替代原正式报告的历史证据或验收结果。

## 评价边界

采样从首次录到的 FOLLOW 时钟后 1 秒开始，每 2 秒一个固定机会，覆盖最终录制时钟；不按检测成功、跟踪成功、可见性或 PASS/FAIL 选帧，也没有 45 张上限。尾部缺图、重复来源时间、未知几何、排除项和原 terminal 状态都保留，不能把缺失的可见目标当成真负样本。

所有同类 actor 均纳入离线几何提议。stage3 包括云台中位场景，也要求独立物理相机姿态与光学 TF 的动态证据；不能用命令角度、最终姿态或固定安装假设填补缺失。生成框是 **amodal 几何提议**，并非自动确认的可见目标标签。

离线推理复用原模型与记录配置、schema2 低置信度缓存及原检测指标 API，不自动下载模型。失败/基础设施槽若无实际图像，检测指标为 null，原分母和失败状态仍保留。经审查的可见子集不等于全飞行准确率，不证明在线 FPS、端到端时延、完整 ReID 或某算法全面优越。

## 查看与复验

在本目录执行以下命令只描述组件，不创建实际协议或执行提取/推理：

```bash
python -B prospective_detection_dataset.py describe
python -B evaluate_prospective_detection.py describe
```

源码快照不是独立打包的完整运行环境。实际操作与合成复验依赖显式选择的原项目源码辅助函数及其依赖；不会自动搜索/替换冻结源码。若以后要复验合成组件，请先准备对应 Python 依赖（包括 NumPy 及源码辅助函数所需依赖），在本目录显式指定源码检出根，例如：

```bash
UAV_DETECTION_FIXTURE_ROOT=/path/to/source-checkout python3 -B -m unittest -v test_prospective_detection test_prospective_detection_independent01
```

该命令只供后续人工选择执行，本次快照没有运行；新复验不会替代附带原回执。具体接口、源绑定、标签独立审批及占位参数详见 `prospective_detection_handoff02.md`。真实计划/协议、实际提取、推理、标签审批与外部附件仍须按上述顺序安排。
