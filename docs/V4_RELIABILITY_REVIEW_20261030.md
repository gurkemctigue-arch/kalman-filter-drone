# 剩余可靠性问题复核（2026-10-30）

本记录只核对现有源码和已保存的小型评价文件，没有启动新飞行、回放 rosbag 或生成新实验统计。v3 历史结果属于 Ubuntu 24.04/Jazzy；本轮 v4 开发验证使用独立 Ubuntu 22.04/Humble。两套结果不合并，也不能视作同条件配对比较。

## 当前结论

四类主要问题均未达到本轮最终验收。已有针对性代码修复、基础设施验证和局部飞行证据，但汽车可靠性、全任务稳定性、汽车主动云台收益、身份未知覆盖及新版四法比较仍需完成。

最新 Humble21 的四个 ROS 包构建、导入隔离及真实消息序列化检查通过；Linux 测试运行 1302 项，零失败/错误、2 项跳过，即 1300 项通过。单测不能代替真实闭环验收。

最新 12 格核心开发批次已停止：六个行人场景为 1 FAIL、5 EVALUATION_PENDING；第七个汽车速度场景为 INFRASTRUCTURE_ERROR；剩余五个汽车场景未执行。最后停止时间为北京时间 2026-10-29 20:13:59，外层执行于 20:14:00 结束。该批次不是正式十种子重复实验。

5 个 EVALUATION_PENDING 的原记录原因都是导航数值性能门尚未 REGISTERED，不能计为 PASS。1 个行人 FAIL 包含长丢失后显式重选未满足持续跟踪检查。汽车停止的直接触发条件是监管节点状态接收墙钟年龄 11.166 秒超过 10 秒；底层调度/传输原因尚未确定，不能认定为内存不足。

4 项安全开发专项、16 格扩展开发和本轮 120 核心加 160 扩展的正式实验尚未开始，正式仍为 0/280。原始失败、待验收、未知和删失均保留。

## 云台与身份的局部证据

同一 seed004 的行人中位和主动云台，归一化画面中心误差 RMSE 分别为 0.12905 和 0.04178，画面地平线误差 RMSE 分别为 0.010061 和 0.004997 rad。画面中心统计分别基于 381 和 369 个可检测样本，不能视作相同样本支持上的多种子因果比较；它只说明本开发种子出现了局部改善。

行人交叉任务完整身份分母为 470：359 correct、0 wrong、111 unknown；多目标主动云台为 460：352 correct、0 wrong、108 unknown。可确认正确比例下界分别为 76.38% 和 76.52%，并非全程 100%。

Humble21 中的 `recorded_estimator_research/research_report.json` 引用的是旧 `stage1_final_v2_*` 四条录制的条件离线重放，不是本轮新导航四法的正式结果。其故障随机种子也不是独立重复飞行。原 v3 算法研究的负结果与局限不改写。
