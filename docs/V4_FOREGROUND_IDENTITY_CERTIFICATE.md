# 离线完整静态网格前景身份证据

规则版本：`whole_static_mesh_optical_z_front_v1`。固定间隔为 **0.05 m**，不是依据开发录制误差拟合的阈值。本规则须随最终评价源码、资产和协议在正式实验前冻结。它只补充离线指定目标身份评价；运行时继续拒绝已知重叠框的完整导航几何，观测/预测时效、身份关联和控制验收门不变。

旧规则把所选 GT 框与任意同类 GT 框的正面积重叠都记为身份未知。框是完整静态网格的无视遮挡投影，两个框相交并不必然表示前面的目标被遮住。新规则保留原来的唯一 `IoU >= 0.5`、新鲜检测、所选 GT 完全位于画面、快门及其前后各一秒保护条件。若图像匹配存在多个可行物理 ID，仍为未知；深度不能参与挑选 ID。

只有正重叠时才检查额外证据：

1. 同类三个预期 actor 均有独立投影，ID 集合必须与前瞻声明完全相同。不能忽略 `project_mesh` 返回空的 actor；返回空既可能是画外，也可能是穿过近裁剪面的物体。
2. 车辆、三个 actor，以及主动云台情况下用于投影的物理 base/camera GT，在 RGB 原始采集时刻均有相差不超过 `1e-9 s` 的有限、一致样本。缺少精确样本时，原有插值仍可用于历史无视遮挡标签，但不能获得新前景证书。反馈 TF 只保留原来的独立交叉核验角色。
3. 深度界来自完整刚性渲染网格的所有顶点，并使用同一时刻、同一光学相机坐标系的 z。三个 actor 的界都必须满足 `0.1 < z_min <= z_max` 且有限。
4. 对每个与所选 GT 框正重叠的其他 actor，严格满足 `other.z_min > selected.z_max + 0.05 m`。等号、深度区间相交、所选为后景、缺少范围或不完整证据均保持未知。

此充分条件的证明很直接：固定像素射线上的三维点写作 `z * [u, v, 1]`；所有 z 为正时，z 的次序就是沿射线的前后次序。三角形内部的 z 是三个顶点 z 的凸组合，因此全顶点最小/最大值也包住所对应的全部三角面。若所选网格的最大 z 仍严格小于另一网格的最小 z，另一 actor 的任何表面都不可能挡在所选表面之前。它是充分条件；条件失败并不证明实际发生遮挡。

0.05 m 是严格几何分隔余量，不是位置、姿态或时间插值误差的通用上界。该证明依赖本版的完整静态网格、正确缩放/visual 变换及刚性 GT。资产审计拒绝未解析的非零 link 位姿、`relative_to`、额外 frame/joint/include、动画/蒙皮、声明的位移材质或 shader，以及实际 actor visual 与声明模板不一致等情况。

审计还限定保存的运行世界：三个指定 actor、水平地面、已知无人机相机载体、指定方向光和受保护的快门。额外模型或未知场景角色不能被忽略；任何 actor、地面、快门或声明模板内新增的嵌套 model/include/actor 都拒绝证书，不能只检查世界顶层名单。地面与相机载体自可见性仍属于本版场景假设；该证书证明同类 actor 的前后关系，不宣称通用环境中的所有像素都无遮挡。它也不证明检测框轮廓完整、汽车可见面足以求导航中心，或行人足点可观测。

`physical_identity_match` 的可选 `front_visibility_evidence` 参数默认空。旧报告或缺少新证据的输入不能自动升级。新匹配结果的 `foreground_visibility_certificate` 保存版本、固定间隔、实际参与的完整深度界、逐对间隔、场景/资产 SHA、精确源样本和失败原因。首次 REQUEST、逐帧选中轨迹与固定 10 Hz 任务时间审计使用同一规则；时间单元没有新鲜身份观测时仍为未知，不复制证书填充静默段。

无视遮挡 MOT、原来的全部对象清晰可见子集、IDF1/HOTA 的机会分母和选择规则均保持不变。所选前景可知，不意味着后景 actor 同样可见。原 Humble13 录包、报告和失败终态保留；新评价只能生成另外命名、带此版本及源码来源的结果。纯数据回归和静态资产审计不是新版本实际身份通过证据；精确 GT 及实际效果仍须新冻结录制验证。
