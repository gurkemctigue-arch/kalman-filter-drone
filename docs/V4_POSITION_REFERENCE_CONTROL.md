# 位置模式移动参考修复

本页记录开发依据与控制规律，不是新版本飞行通过证明。Humble13的原始失败、删失和终态保持不变。

## 真实开发问题

Humble13固定seed004的行人位置控制槽完整录包、起飞、源时钟和短/长遮挡安全检查通过，但整段实际距离RMSE为1.4536511 m，末尾距离误差约0.8332 m，距离稳定时间右删失。相同开发设计的速度模式距离RMSE为0.8613766 m，末尾稳定。位置模式遮挡前已有约0.63–0.76 m距离误差，重选后恢复也慢；不能通过改验收门消除这个问题。

旧位置参考把`desired - previous_reference`反馈为参考速度，再积分上一参考位置。它让参考自身跟上目标，却没有闭合实际飞行器的位置误差。在理想位置内环`vehicle_velocity = K_inner * (reference - vehicle_position)`下，恒速目标需要`target_velocity / K_inner`的永久参考领先量。若参考收敛到期望跟随位置，机体就永久落后。

实际固件的`PositionControl.cpp`使用位置误差乘位置增益生成速度；本工程严格发送位置设定值，其速度字段为NaN。外层积分参考时使用目标速度前馈，不等于向PX4发送速度前馈。PX4源码默认`MPC_XY_P=0.95`支持上述数量级解释，不能把默认值代替每次实际参数记录或真实飞行结果。

## 最小修复

位置模式继续积分上一参考，但改用实际机位误差：

```
reference_velocity = target_velocity + K_outer * deadzone(desired - vehicle_position)
reference_next = reference_previous + limited_reference_velocity * dt
reference_next = vehicle_position + limited_lead(reference_next - vehicle_position)
```

已有速度、加速度、参考投影和失效重置仍生效。投影后的参考写回积分状态，避免受阻时无限积累；失联后从当前机位重新生成。ROS节点在缺失/无效时间戳、无效姿态等绕过核心更新的失效出口也清除控制器状态，防止新鲜消息恢复时沿用旧参考。

理想未饱和一阶位置内环下，恒速误差满足`e'' + K_inner*e' + K_inner*K_outer*e = 0`，因此可消除上述内环造成的稳态滞后，无需在算法中绑定PX4类型或硬编码其位置增益。这不能消除RGB-D/位姿估计偏差，也没有使用目标真值在线补偿。

开发配置将水平参考领先量由每轴1 m改为每轴2 m，竖直仍为0.5 m，保留原参考速度每轴`[2,2,1]` m/s和加速度每轴`[3,3,3]` m/s²。它给长丢失后重选留出追赶余量；不是放宽观测/预测时效、异常门控或验收标准。向量限制按轴作用，`[2,2,0.5]`不表示水平2 m半径。

## 检查与适用边界

独立小模型回归覆盖不同内环增益下的恒速尾窗误差，以及带速度响应滞后的初始位置差追赶；消息边界回归检查无效时间戳后位置参考从零速重启。它们不代替PX4/Gazebo验收。

实际反馈使闭环增加积分作用，停止、转弯或内环响应较慢时可能增加超调。参考限制也不等于实际飞机的速度/加速度保证；发生机体后退漂移时，参考投影按已有规则优先满足领先量界，可能打破名义参考变化率。因此仍须用新冻结版本完成两类位置飞行、遮挡重选、加减速、视野及实际距离稳定检查。迁移到其他飞控或实机时要复核内环带宽、目标速度与参考领先量的关系。

所有模式仍只输出一种设定值；LOST后悬停并显式重选、观测0.60 s、预测0.75 s、里程计0.50 s与马氏门9.21保持不变。
