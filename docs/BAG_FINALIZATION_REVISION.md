# 录包收尾边界修订

`fullplan_v2` 的两次汽车位置兼容试验均完成起飞和 FOLLOW，但 rosbag2 在停止后的缓存写入与 file-mode zstd 压缩阶段超过 45 秒，bag 进程被 `SIGKILL`，没有生成 `metadata.yaml`。这两条记录及早停清单保留为 v2 基础设施 FAIL。

主副本后续修订把 bag 专用停止等待上限改为 180 秒。它只延长录包最终化等待，不改变检测、估计、控制、飞行时长、安全年龄、压缩格式或评价门限。因为这改变了运行器源码，不能回填 `frozen_fullplan_v2`；正式研究必须使用新的冻结根、计划 SHA、前缀和结果目录。

新冻结版本仍需先完成四包构建、导入隔离和全套测试，然后用独立的短汽车位置飞行确认 `metadata.yaml`、数据库和 zstd 文件完整，再开始新的正式矩阵。v2 已完成的 88 条结果不会并入新版本的统计分母。
