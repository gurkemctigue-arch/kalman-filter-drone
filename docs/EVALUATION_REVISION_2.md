# 评价修订 2：相同仿真时间戳下的重选确认边界

## 问题与修正范围

`TargetState` 的 MEASURED 消息保留图像采集时间，评价使用 `max(header stamp, received_sim_s)` 表示系统收到该状态后的运行时间。`received_sim_s` 来自最近一次录制的 `/clock`，因此多条不同先后顺序的状态可能具有同一个运行时间。

原评价只保存重选确认时间，再以 `confirmation_time_s <= state.time_s` 截取后续状态。在确认之前、但与确认同时间戳的旧目标 LOST 会被误计为确认之后的失败。此外，入口按图像时间排序后，不能仅依靠后续排序的稳定性恢复原始录制顺序。

修订 2 保持原有仿真时间定义、观测新鲜度、持续时长、证据间隙和控制宽限阈值，仅修正记录顺序与区间边界：

- bag 解码时保留 `record_sequence`，即过滤后 reader 的零起点读取顺序；计数包含时钟及无法解码的条目，允许序号有空隙。
- 无序号的内存测试输入在任何排序之前按原始列表顺序统一补序。部分记录有序号、部分没有时拒绝输入，避免伪造跨记录顺序。
- 运行时间相同的消息按录制序号排序，防止先按图像时间排序改变并列记录的真实先后。
- 重选确认保存实际确认记录的 `confirmation_record_sequence` 和 `confirmation_state_index`。
- 持续追踪以全局录制序号界定，从该确切记录开始，保留该记录及之后的全部状态和控制。确认前同时间戳或略未来时间的旧 LOST 排除；确认后同时间戳的 LOST、歧义或身份变化仍然 FAIL。
- 确认后运行时间回退的记录也保留，新增时间顺序检查明确判失败；不能以 `time_s < confirmation_time_s` 将其移出评价区间。原有试验终点上界保留。
- 确认候选中的第一条 active 状态按录制顺序审查，必须自身确认新任务；请求之后录入但时间回退的 active 状态也纳入候选，回退时不确认。原时间范围内的候选继续保留，对同时间戳旧 active 保持原有保守拒绝行为，不能跳过旧 active 状态，搜索后面匹配 UUID 的消息来追认成功。
- 单独调用持续评价时必须提供确切序号或确切状态列表索引。缺失边界、找不到记录或边界时间不符时返回 INCOMPLETE_EVIDENCE，不猜测起点。

阶段二的运行时间转换同样保留序号。真实初选和重选使用真实确认记录；只有一次初选时，另行标记的最后 5.2 秒尾窗以窗口内第一条状态记录为锚点，无论其状态或身份是什么，不能寻找后续匹配目标而跳过坏记录。锚点本身无效时，尾窗评价仍须失败。

本修订没有将 `>=` 改为 `>`，没有增加 epsilon、额外宽限期，也没有删除所有并列时间戳消息。所有丢失记录继续保留在整次试验的状态统计中。

## 版本与历史记录

输出保持 `schema_version: 3`，新增 `evaluation_revision: 2`。原来不含该字段的冻结输出属于本修订之前的评价结果；不能仅根据 schema 3 声称其已经应用本修订。

`frozen_fullplan_v1` 首 8 次试验按原样保留，包括原始 bag、telemetry、日志、子清单及 7 PASS / 1 FAIL。汽车 raw 的原始 FAIL 不覆盖，也不改写成原试验当时已通过。

在完成修订及验证后，新冻结 `fullplan_v2` 将从头执行主研究全部 166 次。预注册使用 `study_revision` 区分冻结研究。v1 的 8 次属于历史证据，不拼接为 v2 的独立重复次数，也不复用录制填充新研究。修订不依据跟随误差调参；新冻结仅纳入评价记录顺序修正及 ROS 退出幂等修复。研究执行完成与试验全部 PASS 仍然分别报告，失败和缺失不删除。

若核对 v1 汽车 raw 录制，使用修订 2 独立生成同目录 `offline_evaluation_revision2.json`，保留 `offline_evaluation.json` 不变。另存小型审计 JSON，包含修订评价脚本 SHA、原研究 plan SHA、原输出 SHA、同时间戳 reader 序号及新旧结果。新文件只表示相同录制的新版离线重评价，不代表重飞，也不能回写 v1 原始清单。bag 中同时间戳记录的 reader 序号应另外核对，不能仅从 telemetry 推断 bag 的确切顺序。

## 验证边界

轻量单元测试覆盖源时间与接收时间不同、确认前后记录具有相同运行时间、旧 active 状态不能跳过、显式序号经过源时间排序仍可还原顺序、缺少精确边界不能通过等情况。这些测试不启动 ROS、Gazebo、PX4 或 YOLO，不替代真实 bag 核对和新冻结研究。
