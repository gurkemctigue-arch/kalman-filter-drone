# 阶段二、三预注册清单的离线统计

`scripts/summarize_stage23_matrix.py` 只读取 matrix manifest 及其明确引用的飞行/云台评价 JSON，不启动仿真、不读 bag、不运行检测，也不修改试验清单或原始报告。

```bash
python scripts/summarize_stage23_matrix.py results/stage23_matrix_v1/manifest.json \
  --output results/stage23_matrix_v1/statistics
```

项目整体迁移后，可用 `--project-root` 指定副本根目录。只有清单中已记录的评价报告可以重新定位；不会自动采用未被清单引用的目录或补算缺失试验。输出保留 manifest 和报告文件哈希。

阶段二按类别/场景统计计划数、失败/中断、待运行、运行中和已验证通过数。阶段三按类别和同 seed 的 midpoint/active 两项配对；除运行名称、ID 和云台模式外，所有计划参数必须相同。计算方向统一为 `active - midpoint`，不把不同种子混成两个不配对样本集。

每个指标提供三组独立统计：所有已有测量的配对、两次均通过的配对、至少一次失败或未完成但仍有测量的配对。失败试验的数值留在逐次表和第三组中；缺失值保持空值，不补零。所有可读数据组包含短时失败记录，属于可用数据描述，不能解释为覆盖所有失败结局的完整效应估计。

默认对每个 seed 的单次指标差值进行 10000 次非参数 bootstrap，输出均值和 95% percentile 区间，随机种子固定为 20261027。重复单位是 seed 配对，不是视频帧，也不是 bootstrap 次数。只有一个有效配对时保留点估计，置信区间为空；少于十组时明确标记未达到建议重复数。多指标区间未进行多重比较校正，不输出显著性或 p 值结论。

所有失败比例均使用对应分组的全部预注册项目作分母，默认全局分母为 66，阶段三每类每模式为 10。未执行项目单独列出，因此进行中的计划失败比例不能当成最终失败概率。声明 PASS 但报告缺失/无效的项目也单独列出，不能进入“两次均通过”的条件统计。

已有指标包括画面中心、独立真值地平线、物理反馈与 TF 几何误差、关节实际转动范围和命令/反馈差、跟随距离/高度、车辆速度。各指标保留单位、范围和参考定义：速度 RMS 不是速度跟踪 RMSE；关节范围和最大伺服滞后不是控制抖动。当前 JSON 没有命令抖动或独立标定后的状态估计 RMSE，这些明确列为缺失，不生成替代值。

输出 `statistics.json`、逐次测量 `trial_measurements.csv` 和每个计划配对的差值 `seed_pair_differences.csv`。失败报告、缺失原因、实际记录区间及参数不一致原因均可追溯。物理身份 IDF1/HOTA 和检测 mAP 仍使用独立标签研究管线。
