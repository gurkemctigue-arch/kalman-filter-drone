# 本地可视化验收入口

在项目目录执行 `python scripts/build_acceptance_dashboard.py`，从已有本地归档生成 `results/验收总览.html`。`results/` 按 `.gitignore` 排除，不随公开源码提交；浏览器直接打开生成的文件即可，不需要运行 ROS、服务器或网络服务。公开克隆的结果工件边界见 [结果工件说明](RESULTS_ARTIFACTS.md)。

生成器只读已有结果，不运行测试、Gazebo、PX4 或新评价。它自动发现 `stage1_` / `stage2_` / `stage3_` 录制目录，也读取 `run_config.stage` 识别 `stage23_engineering_...` 等统一矩阵前缀；保留失败、无结果及缺少视频/bag/版本记录的试验。页面将单次工程证据、独立物理身份和研究矩阵分别列出，不能把单元测试或一份 PASS 报告计为整阶段完成。

每次录制可以播放原始视频、查看抽样关键帧、展开逐项检查与失败清单，并打开原始配置、监控、评价 JSON、日志及 bag 元数据。有 `identity_review/identity_review_*.jpg` 时也链接到按采集时间对齐的身份接触表。普通 `frame_*.jpg` 只是抽样证据，页面不会猜测其采集时刻。

统一矩阵产生的 `flight_evaluation.json` 与唯一实例专用 `auto_unique_evaluation.json` 均按实际文件读取。对保留历史评价器版本的录制，云台采用最高受支持 schema（当前 3），唯一实例评价采用最高受支持 schema（当前 2），选择与 PASS/FAIL 无关；具体采用的文件及旧版本结果同时显示。不能按结果挑选旧 PASS 覆盖新 FAIL，未知 schema 不能提供通过证据。唯一实例多候选测试未建立指定物理任务时，身份评价明确为不适用。

阶段二的独立身份统计保留所有任务机会分母，分别显示已知身份、正确比例下界、错误个体、无新鲜检测和 unknown；已知帧正确 100% 不能掩盖长时失联。阶段三云台物理/几何评价和独立跟随/遮挡评价分列，缺失后者时不能推断完整闭环验收。

若独立物理评价确认 `WRONG_PHYSICAL_ACTOR > 0`，该次录制的总体状态为失败；原有安全检查通过的结果仍单独保留，便于区分“控制状态机安全”与“实际跟错个体”。unknown、无新鲜检测以及零已知样本不等同于错误个体；页面将其显示为身份未知/证据不足，并继续保留全部任务机会分母。仅有已知帧无错配时显示“已知帧未见错配（未知仍保留）”，不显示物理身份全程通过。

原始身份 JSON 中的 HOTA/IDF1 需按标注范围解读：`amodal_simulation_mot` 是可能含被遮挡投影框的诊断约定；`unoccluded_geometry_mot` 是完整入画、同类投影框 IoU 不超过 0.01、处于遮挡器保护区间之外的几何候选子集，仍需图像可见性复核。指定物理身份在正面积同类框交叠且没有完整前景证据时给 unknown；当前 v4 只有 `whole_static_mesh_optical_z_front_v1` 的严格离线例外，限于已声明的三刚体封闭场景，要求完整静态网格、精确源时刻和全部相关投影，并证明所选整个网格位于每个相交目标之前、光轴深度间隔严格超过 0.05 m。地面和载机自遮挡仍沿用既有场景假设，快门前后各 1 s 保护不豁免；其完整条件见[阶段二协议](STAGE2_IMPLEMENTATION.md)。所以同一帧仍可能属于几何 MOT 子集而物理身份未知；不能用框中心远近或 UUID 连续消除 unknown。旧报告保持原规则，两类指标都不能替代完整任务时间的身份覆盖统计；指标公式验证通过也不替代标签验证。

研究重复报告显示 `planned` / `started` / `complete` 计数；未开始的计划仍保留在分母。失败试验收齐也可属于运行记录 complete，但不等于方法有效或统计显著。离线噪声重放与独立飞行重复分开；待视觉复核的检测 proposed 指标不能显示为正式 mAP 通过。TrackEval 公式对照仅是评价代码验证。

若检测报告已有 `reviewed_aggregate`，页面显示已复核可见子集的 mAP，并同时列出实际运行阈值处的 Precision、Recall 和漏检 FN；AP 的置信度扫描不能掩盖运行阈值下的漏检。`research_figures/manifest.json` 中存在的独立 PNG/SVG 会以内嵌图片和矢量图下载链接呈现，输入文件哈希和图表适用边界链接到原 manifest。缺图保留提示；绘图 manifest 不计作研究矩阵执行完成。

可用 `--results-dir PATH` 指定主结果目录，或多次 `--additional-results-dir PATH` 索引另一个冻结研究副本。所有链接都是相对 HTML 文件的本地路径；归档到 Windows 时须保留被索引的相对目录结构。只复制 HTML、不复制视频/JSON/bag，不能形成完整可复查的验收包。
