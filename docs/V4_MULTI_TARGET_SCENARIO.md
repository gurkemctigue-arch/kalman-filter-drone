# v4多目标交叉任务的前瞻修订

本页定义新的开发/正式场景，不宣称新飞行已经通过。Humble13周期交叉的原始记录和失败不变，新任务与旧任务不混池比较。

## 一次完整换道与恢复观察

核心`stage2_crossing`和`stage3_multi_active`采用三个同类物体，其中两侧物体完成一次平滑车道交换，再在交换后的车道继续前进。被选中心物体继续沿前向运动。两类别使用相同轨迹函数、不同预先声明的横向尺度。

原实现使用周期30 s的正弦横向速度：前15 s交换，随后返回，45 s任务末段又进入下一轮。Humble13中，末段检测框再次重叠使保守导航拒绝测量、达到原0.75 s预测界后悬停，恢复后剩余时间不足末端3 s稳定要求。该安全动作没有自动换人，但原任务的持续跟踪/距离性能失败应保留。

新任务采用位移`2*A`的五次平滑换道。前2 s共同加速、随后2 s直行不变；换道持续18 s，侧向速度与加速度在两端均为零，之后不再自动返回。选择18 s的依据是匹配原首次正弦换道的峰横速：`3.75*A/T = A*(2*pi/30)`得到`T=17.905 s`，取最近整数秒。它不是依据正式结果选择的时间。

名义换道中心在FOLLOW后13 s、完成在22 s。实际Gazebo路径、航向、分离和恢复必须从独立真值检查，不能把名义时间当实际成功。短快门仍在原12 s附近，因此新旧交叉曝光时间并不完全一致；不能称同轨消融。

## 保留的验收要求与边界

45 s全区间的导航可用率、物理身份已知覆盖、距离/高度误差、遮挡安全与末端稳定要求均保留；交叉中发生的未知、暂停和错误照计，恢复观察窗不能用来裁掉困难片段。所选目标仍由框选和RGB-D在线跟踪确定，场景实体名与真值不参与在线身份或控制。

运行时继续拒绝截帧/重叠框的完整几何推断，后景车辆残面不能被猜成完整端面。这个场景修订覆盖“一次交叉、分离和跟随恢复”，不能证明周期重复交叉下持续导航可用。Humble13提供后者的失败/局限证据；另外四条独立歧义安全专项仍必须强制触发多候选或关联多解，检验悬停、不换人及实际低速。

独立物理身份评价若采用新的全网格深度范围前景证明，另行记录评价修订；它只影响离线证据判读，不能称为运行时遮挡处理能力提升，也不能自动扩大MOT可见标签子集。
